# akshaypakhare.github.io

Personal site of Akshay S. Pakhare — postdoctoral research associate, School of
Engineering, Brown University. Multiphysics of materials that break:
mechanical engineering, materials science and electrochemistry.

Live at `https://<username>.github.io`.

## Structure

```
index.html      the entire site (no build step, no dependencies)
images/         figures reproduced from published papers
NOTICE.md       copyright and licensing — read before reusing anything
PUBLISHING.md   how this gets deployed and updated
LICENSE         MIT, covering the site code only
```

Navigation is hash-based (`#research`, `#tutorials`, …), which is why GitHub
Pages serves it with no configuration.
